# Classificação integral dos commits da API

Levantamento de **todos os 67 commits alcançáveis em main**, do primeiro commit até `77c1c93f57cce23b7d0f2ddf3c84bc3b15b1d68e`, reconstruído em 28/09/2026 (São Paulo). O ajuste atual de metadados acrescenta o PATCH **0.12.1**.

## Critério da reconstrução

- MINOR para um novo ciclo funcional ou operacional substancial, incluindo o primeiro backend (0.1.0). O ciclo pode precisar de vários commits de schema, configuração, serviço e controller; seus componentes compartilham a versão.
- PATCH para uma correção de comportamento, segurança, compilação ou execução operacional. Reparos de vários arquivos da mesma regressão formam um único PATCH.
- Testes, documentação e formatação equivalente mantêm a versão. Regressões intermediárias sem entrega utilizável também não criam nova funcionalidade.
- Merges comuns não contam duas vezes. `6e3b195` é uma exceção verificada: introduz código de endereço/rota além de integrar segurança; comparado com o segundo pai, tem cinco arquivos adicionais.
- O diff prevalece sobre o título: `122987f` acrescenta queuedAt; `2077601` inclui uma rotina nova de backup; `77c1c93` acrescenta metadados do deploy e validação de release.
- Cinco tentativas de formatação no ciclo de e-mail introduziram barra-n literal, quebrando a sintaxe. Seus reparos são classificados como correção de compilação, sem presumir que esses snapshots foram implantados.
- MAJOR permanece zero durante desenvolvimento/homologação. As mudanças de contrato do cadastro de cliente e de funcionários estão explicitadas nos ciclos 0.6.0 e 0.9.0, com atualização coordenada dos consumidores.

**As versões anteriores abaixo são atribuídas retrospectivamente.** Os commits originais não foram reescritos e não se afirma que existiam releases, tags ou deploys com esses números. A coluna indica o ciclo ao qual cada commit pertence; componentes intermediários podem não ser executáveis isoladamente. O primeiro número efetivamente gravado após esta revisão é 0.12.1. O valor 0.2.0 gravado por `77c1c93` permanece no histórico Git e fica documentado como a consolidação anterior substituída.

## Escopo dos quatro repositórios

A versão exibida por `/v1/health` pertence a **APIBonamassa**. Commits exclusivos de BonamassaPainel, BonamassaAndroid e BonamassaEntregador não são somados a ela: cada consumidor mantém sua própria versão. As funcionalidades da API utilizadas pelos quatro estão incluídas acima. Este levantamento cobre todos os commits da API, inclusive ancestrais em branches já integradas, e não apenas os commits first-parent ou os títulos com prefixo feat/fix.
